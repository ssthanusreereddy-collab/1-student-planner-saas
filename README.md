# Smart Student Planner

A beginner-friendly student planner web app for managing study tasks, subjects, and due dates. This is a front-end demo built with HTML, CSS, and JavaScript.

## Features

- Add study tasks with a subject and due date
- Mark tasks as completed
- Filter tasks by all, pending, or completed
- Delete tasks
- Dashboard counts for total, completed, and pending tasks
- Saves tasks in the browser using `localStorage`
- Responsive layout for mobile and desktop

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Add your first task.

No installation or build step is required.

## Publish with GitHub Pages

1. Create a GitHub repository named `student-planner-saas`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings**.
4. Select **Pages** in the sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then save.
7. Wait for GitHub Pages to publish your site. The Pages screen will show the website URL.

## Important note

This is a starter project, not a complete production SaaS. Tasks are stored only in the current browser and are not synced between devices. It does not yet include user accounts, a server database, AI features, or subscription payments.
